# BeautyAI Flutter App

This is the Flutter source code for the BeautyAI Salon Booking application.

## How to Run
1. Ensure you have [Flutter installed](https://docs.flutter.dev/get-started/install).
2. Open this folder in VS Code or your preferred IDE.
3. Run `flutter pub get` to install dependencies.
4. Run `flutter run` followed by selecting your preferred device/emulator.

## Structure
- `lib/main.dart`: Entry point and routing.
- `lib/screens/`: All application screens (Home, AI Analysis, Bookings, Profile, etc.).
- `lib/widgets/`: Reusable widgets (Custom Bottom Navigation).
